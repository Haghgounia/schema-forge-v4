# SchemaForge V4 4.0.0 - Distribution Documentation

This directory contains the operator-facing documentation shipped with the SchemaForge V4 4.0.0 runtime distribution.

Read in this order:

1. `INSTALLATION.md` - prerequisites, extraction, configuration, startup, and first verification.
2. `CONFIGURATION.md` - supported external runtime properties and environment variables.
3. `OPERATIONS-GUIDE.md` - start, verify, stop, logs, failures, and support evidence.
4. `API-GUIDE.md` - frozen REST surface for V4.
5. `DBA-GUIDE.md` - database-facing behavior, live metadata usage, and read-only Schema Conformance Audit.
6. `RELEASE-NOTES-4.0.0.md` - frozen V4 GA capability scope.
7. `KNOWN-LIMITATIONS-4.0.0.md` - deferred and environment-dependent limitations.
8. `VALIDATION-EVIDENCE-4.0.0.md` - regression, live audit, API smoke, and GA checksum evidence.

The runtime distribution is not a developer source package. Maven, source code, test classes, and build reports are not required to run the packaged application.
