# R7.5 Comprehensive ALTER Acceptance

## R7.5A Offline Matrix

`ComprehensiveAlterAcceptanceTest` is a test-only acceptance gate. It does not modify production code.

Coverage across Oracle, PostgreSQL, Db2 for z/OS, SQL Server and MySQL:

- ADD COLUMN
- DROP COLUMN
- ALTER TYPE
- NULL / NOT NULL transition
- DEFAULT transition
- IDENTITY transition
- generated-expression transition
- PK ADD / DROP / REPLACE
- UK ADD / DROP / REPLACE
- FK ADD / DROP / REPLACE
- CHECK ADD / DROP / REPLACE
- INDEX ADD / DROP / REPLACE
- destructive SQL remains blocked/commented under safe defaults
- identical live/desired model yields zero residual diff

## Verification

```bat
mvnw.cmd -Dtest=ComprehensiveAlterAcceptanceTest test
```

After this passes, run the existing migration baseline together with the new acceptance gate:

```bat
mvnw.cmd -Dtest=ComprehensiveAlterAcceptanceTest,SchemaDiffEngineTest,MigrationSqlRendererTest,MigrationGenerationServiceTest,MigrationArtifactProducerTest test
```
