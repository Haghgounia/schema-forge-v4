# SchemaForge V4 - C8.8-R1 Batch Diagnostic Provenance Test Repair

Status: **TEST-ONLY REPAIR / USER-VERIFIED / INCLUDED IN OFFICIAL C8.8**

## Failure evidence

The first C8.8 targeted gate compiled `274` main and `187` test Java files and finished `39 / 1 / 0 / 0`. The only failure was `BatchGenerationOrchestratorTest.batchGenerationPreservesFaultIsolationDiagnosticsManifestAndLedgerIdentity` at the provenance assertion.

## Root cause

The test selected every `SUMMARY_REPORT` and `ERROR_REPORT` in the merged batch Ledger. Valid batch Mermaid/Graphviz summaries and the per-document CRUD summary use their own producer identities, so requiring every selected record to use producer `SchemaForgeApiService` was incorrect. C8.7 production behavior already allowed these producer identities.

## Repair

R1 changes only `src/test/java/com/behsazan/schemaforge/application/BatchGenerationOrchestratorTest.java`:

- select diagnostic descriptors only when type is summary/error **and** `logicalName` is exactly `batch-generation`;
- assert exactly two matching descriptors;
- verify those two preserve producer `SchemaForgeApiService`.

`src/main` is byte-for-byte unchanged from the C8.8 extraction candidate.
