# R7.1 — MySQL Final Recovery Closure Gate

R7.1 hardens `MySqlFinalRecoveryGenerationIT` from an evidence-generation runner into an acceptance-grade
closure gate for the 5,321-snapshot legacy canonical corpus.

## Acceptance invariants

- Persisted canonical `*.schema.json` files are never mutated.
- Only exact DB2 `SYSCOLUMNS`, unanimous historical numeric evidence, and confirmed P2-R7/P2-R8/P2-R10
  directives may fill missing exact-numeric precision.
- Every discovered canonical snapshot is accounted for as either loaded or read-failed.
- Snapshot read failures are written to `mysql-final-snapshot-read-failures_*.csv` and fail the gate by default.
- A partial corpus cannot pass silently: `schemaforge.mysql.final.expectedMinSnapshots` defaults to `5321`.
- Cumulative generation cannot regress silently: `schemaforge.mysql.final.expectedMinGenerated` defaults to `4702`.
- Every successfully loaded snapshot must finish in exactly one state: generated, hard-blocked, or generation-failed.
- Residual unsupported or conflicting cases remain explicit hard blockers; no datatype guess or precision clamp is allowed.

## New R7.1 properties

| Property | Default | Purpose |
|---|---:|---|
| `schemaforge.mysql.final.expectedMinSnapshots` | `5321` | Reject an accidentally partial legacy corpus |
| `schemaforge.mysql.final.expectedMinGenerated` | `4702` | Reject cumulative recovery coverage regression |
| `schemaforge.mysql.final.failOnSnapshotReadErrors` | `true` | Fail when any discovered canonical snapshot cannot be read/mapped |

`schemaforge.mysql.final.failOnGenerationErrors=true` should also be used for the closure run.

## Required evidence directories

The runner consumes the latest matching CSV in each supplied directory:

- P2-R2: `mysql-metadata-recovery-details_*.csv`
- P2-R7: `mysql-strong-table-reconciliation-applied_*.csv`
- P2-R8: `mysql-cross-schema-reconciliation-applied_*.csv`
- P2-R10: `mysql-historical-column-corroboration-details_*.csv`

## Windows closure command

```bat
mvnw.cmd ^
  -Dtest=MySqlFinalRecoveryGenerationIT ^
  -Dschemaforge.mysql.final.snapshotDir="D:\Sample-Docs-Scripts\Legacy\SchemaForgeCanonicalJson-20260818" ^
  -Dschemaforge.mysql.final.db2SysColumnsFile="D:\SYSCOLUMNS-050511.zip" ^
  -Dschemaforge.mysql.final.p2r2Dir="D:\Sample-Docs-Scripts\SchemaForge-MySQL-P2-R2" ^
  -Dschemaforge.mysql.final.p2r7Dir="D:\Sample-Docs-Scripts\SchemaForge-MySQL-P2-R7" ^
  -Dschemaforge.mysql.final.p2r8Dir="D:\Sample-Docs-Scripts\SchemaForge-MySQL-P2-R8" ^
  -Dschemaforge.mysql.final.p2r10Dir="D:\Sample-Docs-Scripts\SchemaForge-MySQL-P2-R10" ^
  -Dschemaforge.mysql.final.outputDir="D:\Sample-Docs-Scripts\SchemaForge-MySQL-P2-FINAL-R7.1" ^
  -Dschemaforge.mysql.final.cleanOutput=true ^
  -Dschemaforge.mysql.final.failOnSnapshotReadErrors=true ^
  -Dschemaforge.mysql.final.failOnGenerationErrors=true ^
  -Dschemaforge.mysql.final.expectedMinSnapshots=5321 ^
  -Dschemaforge.mysql.final.expectedMinGenerated=4702 ^
  test
```

If the historical evidence directories have different local names, only the four `p2r*Dir` values should be
changed; the acceptance invariants should remain unchanged.

## Closure evidence to retain

Retain the generated directory plus the five R7.1 report families:

- `mysql-final-recovery-summary_*.txt`
- `mysql-final-recovery-details_*.csv`
- `mysql-final-recovery-applied_*.csv`
- `mysql-final-hard-blockers_*.csv`
- `mysql-final-snapshot-read-failures_*.csv`

R7.1 is complete only after the closure command passes on the intended full legacy corpus. Hard blockers are
allowed when explicitly classified; snapshot read failures and generation failures are not.
