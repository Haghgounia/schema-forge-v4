SchemaForge Diagram Export Extension
===================================
Base baseline : SCHEMAFORGE-V4-FINAL-20260814
Extension     : MERMAID-PHASE2-CANONICAL-JSON-PILOT

historical snapshot corpus (only when explicitly enabled) and emits real UTF-8 .mmd artifacts plus selection,
