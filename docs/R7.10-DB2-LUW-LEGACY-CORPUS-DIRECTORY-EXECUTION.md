# R7.10 Db2 LUW Legacy Corpus Directory Execution

## Purpose

Execute SchemaForge-generated `.db2luw.sql` files from the historical Legacy Word canonical JSON corpus against a disposable Db2 LUW database through JDBC, with durable reports.

## Important corpus semantics

The Legacy Word corpus is historical. Multiple canonical snapshots may describe different revisions of the same qualified table. SchemaForge must not guess a single authoritative revision.

`HISTORICAL` mode therefore:

- recursively executes every generated Db2 LUW SQL file;
- creates missing schemas using the connected authorization ID;
- drops the table/sequence represented by the current script before replay when `dropBeforeCreate=true`;
- skips cross-table foreign keys by default, because historical revisions do not form one dependency-complete final schema;
- skips grants by default;
- executes CREATE TABLE, local constraints, indexes, comments and other table-local DDL;
- writes file-level and statement-level reports under `target/db2luw-sql-execution-report/<run-id>`.

The final database after HISTORICAL replay is execution evidence, not a consolidated production schema.

## Safety

Db2 DDL can commit. Destructive replay requires:

`I_UNDERSTAND_DB2_LUW_DDL_MAY_COMMIT_AND_DROP_TABLES`

The runner also verifies `VALUES CURRENT SERVER` against `db2luw.sql.expectedDatabase` before execution.

## Example execution

```bat
mvnw.cmd ^
  -Pdb2luw-live ^
  -Dtest=Db2LuwDirectoryExecutionTest ^
  -Ddb2luw.sql.root="D:\Sample-Docs-Scripts\SchemaForge-R7.10-P5-DB2LUW-OBSERVE" ^
  -Ddb2luw.sql.fileSuffix=".db2luw.sql" ^
  -Ddb2luw.jdbc.url="jdbc:db2://localhost:50000/SFORGE" ^
  -Ddb2luw.jdbc.user=db2inst1 ^
  -Ddb2luw.jdbc.password=Schemaforge123 ^
  -Ddb2luw.sql.expectedDatabase=SFORGE ^
  -Ddb2luw.sql.executionMode=HISTORICAL ^
  -Ddb2luw.sql.createMissingSchemas=true ^
  -Ddb2luw.sql.dropBeforeCreate=true ^
  -Ddb2luw.sql.skipForeignKeys=true ^
  -Ddb2luw.sql.skipGrants=true ^
  -Ddb2luw.sql.failOnErrors=false ^
  -Ddb2luw.sql.confirmDestructive=I_UNDERSTAND_DB2_LUW_DDL_MAY_COMMIT_AND_DROP_TABLES ^
  test
```
