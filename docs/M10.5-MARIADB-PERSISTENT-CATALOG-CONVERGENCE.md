# M10.5 - MariaDB Persistent Catalog Convergence

M10.5 is a read-only live gate over the persistent MariaDB schema created by M10.4.

It consumes the M10.3 closed-selected CSV, reloads the exact persisted canonical snapshots, and reads the deployed database through `JdbcMariaDbMetadataRepository`. Each live table is compared to the selected canonical table with the existing MariaDB-aware `SchemaDiffEngine`.

Evidence includes:

- selected/loaded table count and selection-contract mismatches;
- live, missing, and extra table counts;
- expected/live counts for columns, primary keys, unique keys, checks, indexes, and foreign keys;
- every residual column or table-object drift;
- `Cohort converged` and `Exact database converged` flags.

The gate never mutates MariaDB. Missing selected tables and residual structural drift are fatal by default. Extra live tables are reported but are non-fatal by default so unrelated pre-existing objects can be distinguished from drift inside the M10.3 cohort. Set `schemaforge.m10.mariadb.validation.failOnExtraTables=true` when the database is expected to contain only the closed cohort.
