# Step 11 - PostgreSQL Constraints, Indexes and Dual-Database Directory Runner

## PostgreSQL DDL completion

The foreign-key generator now renders both model attributes:

- `ON DELETE`
- `ON UPDATE`

Supported actions:

- `RESTRICT`
- `CASCADE`
- `SET NULL`
- `SET DEFAULT`
- `NO ACTION` (omitted because it is the PostgreSQL default)

Regression coverage now includes:

- composite primary key
- composite unique constraint
- composite unique index
- ascending/default and descending index columns
- `ON DELETE CASCADE`
- `ON DELETE SET NULL`
- `ON UPDATE RESTRICT`
- `ON UPDATE SET DEFAULT`

## Directory runner

Test utility:

`src/test/java/com/behsazan/schemaforge/DirectoryDualDatabaseGenerationRunner.java`

Arguments:

1. input directory
2. output directory

For every `.docx` file in the input directory, it creates:

- one Oracle SQL script
- one PostgreSQL SQL script
- canonical JSON files generated by the existing pipeline

The utility prints each generated SQL path and a final summary.
