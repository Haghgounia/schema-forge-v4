# PostgreSQL Feature Parity

Implemented PostgreSQL DDL capabilities:

- Generated identity columns: `GENERATED BY DEFAULT AS IDENTITY`
- Generated stored columns: `GENERATED ALWAYS AS (...) STORED`
- Covering indexes with `INCLUDE (...)`
- Partial indexes with `WHERE ...`
- Expression indexes
- Deferrable primary-key, unique-key and foreign-key constraints

## Canonical model additions

- `Index.includeColumns`
- `Index.predicate`
- `IndexColumn.expression(...)`
- `PrimaryKey.deferrable` and `initiallyDeferred`
- `UniqueKey.deferrable` and `initiallyDeferred`
- `ForeignKey.deferrable` and `initiallyDeferred`

Compatibility constructors from previous versions remain available.
